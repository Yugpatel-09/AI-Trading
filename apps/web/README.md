# TradeForge Web Application (`apps/web`)

Next.js 14 (App Router) + TypeScript + Tailwind CSS web interface for TradeForge.

## Features
- **Design System**: Deep navy (`#0A192F`), Slate (`#1E293B`), and Teal Accent (`#0D9488`), dark/light theme, tabular font for figures.
- **Public Marketing Pages**: High-conversion landing page, transparent pricing, FAQ, SEBI risk disclosure, interactive demo chart.
- **Authentication**: Sign up, email/phone verification, login, mandatory TOTP 2FA.
- **Broker Connection**: Connect Zerodha Kite, Upstox, Angel One, Groww, Dhan; test connection, show token expiry.
- **Dashboard**: Net P&L (post-brokerage and taxes), open positions, real-time AI signal feed with plain-English rationales, instant Pause and Kill buttons.
- **Charts**: Interactive 1m, 5m, 10m charts with Lightweight Charts, VWAP, EMA overlays, and executed trade markers.
- **Onboarding / Risk Limits**: Configure max daily loss, per-trade risk, trading modes (Paper, Approve, Auto).

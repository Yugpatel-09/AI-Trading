# TradeForge Documentation (`docs/`)

Engineering documentation, compliance standards, and architectural blueprints:
- `architecture/`: 8-layer deep dive, sequence diagrams, and multi-tenant data flow.
- `adr/`: Architectural Decision Records tracking technical choices and trade-offs.
- `compliance/`: SEBI algorithmic trading guidelines, DPDP data privacy standards, and mandatory risk disclosures.
- `runbooks/`: Incident response steps for feed dropouts, broker disconnections, and emergency square-offs.
